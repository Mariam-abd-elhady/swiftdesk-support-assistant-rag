SwiftDesk IT Support Assistant

RAG Capstone Project

Project Description

SwiftDesk is a Generative AI assistant designed to help IT support agents draft concise responses to customer support tickets. The system uses Retrieval-Augmented Generation (RAG) to retrieve similar previous support cases and use them as contextual guidance when generating a new response.

Technologies

  • Python
  • Google Gemini API
  • LangChain
  • Chroma DB
  • Sentence Transformers
  • FastAPI
  • Streamlit
  • Pandas
  • ROUGE-L
  • python-dotenv

RAG Workflow

  1. Prepare support ticket data.
  2. Create embeddings for previous support examples.
  3. Store embeddings in a local Chroma database.
  4. Retrieve similar support tickets.
  5. Send the customer issue and retrieved context to Gemini.
  6. Generate an AI support draft.
  7. Review the generated response by a human agent.

Prompt Styles

  • Zero-shot
  • Few-shot
  • Reasoned

Backend

The backend is implemented using FastAPI and provides:

  • GET /health - checks whether the service is running.
  • POST /generate - generates a support response.

Frontend

The Streamlit frontend allows the user to:

  • Enter a customer issue.
  • Select a prompt style.
  • Enable or disable RAG.
  • Select the number of retrieved examples.
  • View the generated AI draft.
  • View retrieved support sources.
  • See the human review requirement.

Evaluation

The system was evaluated using 10 test examples and ROUGE-L. The current evaluation produced an average ROUGE-L score of 0.1150 using the configured evaluation setup.

Responsible AI

The system follows Responsible AI principles including accuracy, respectful language, privacy protection, escalation of risky cases, transparency, and mandatory human review.

Human-in-the-Loop

AI-generated responses are drafts only. A human support agent must review the response for clarity, relevance, politeness, accuracy, and safety before sending it to the customer.
